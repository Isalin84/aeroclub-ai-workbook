# Иллюстрации блоков

Слоты: b0-start, slovar, b1-map, b2-safety, b3-prompts, b4-skills, b5-docs, b6-dashboard, b7-visual, b8-present, b9-vibe, b10-final, boarding - файлы `<слот>.webp`. Тетрадь работает и без них.

Все 13 слотов заполнены 26.10.2026. Иллюстрации созданы встроенным инструментом image_gen в одном стиле: бумажная аппликация в палитре Аэроклуба (графит, красный акцент, белый, светло-серый, сталь, бледно-голубой), тема — авиация и мероприятия.

Задание — `../../../_tools/illustration_prompts.md`. Фактические промпты и происхождение файлов — `../../../_tools/illustration_generation_manifest.json`. PNG-исходники — `../../../_tools/illustrations_src/`: баннеры 2172×724, арт сертификата 1536×1024. Баннеры сразу созданы в пропорции 3:1, чтобы сохранить фигуры и предметы целиком.

Готовые WebP: баннеры 1536×512; `boarding` 1478×1024, с соотношением сторон слота 570:395. Обработка — `../../../_tools/crop_illustrations.py`; поддерживает исходники 3:2 и готовые композиции 3:1. Повторный экспорт: `_tools/.venv/bin/python _tools/crop_illustrations.py`.
