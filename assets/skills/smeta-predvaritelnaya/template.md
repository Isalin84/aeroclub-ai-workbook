# Шаблон предварительной сметы

Образец для скилла `smeta-predvaritelnaya`. Данные в примере вымышленные и нужны только чтобы показать формат. Цены в примере не являются рыночными, это иллюстрация структуры.

## Шапка

| Поле | Значение |
|---|---|
| Мероприятие | [название] |
| Клиент | [название] |
| Дата мероприятия | [дд.мм.гггг] |
| Место | [город или радиус] |
| Участников (ячейка, от неё считаются все количества) | [число] |
| Бюджет клиента, ₽ с НДС | [сумма или «не указан»] |
| Агентское вознаграждение, % | 15 (допущение, уточнить) |
| НДС, % | 20 |
| Версия / дата составления | v1 / [дд.мм.гггг] |
| Статус | Предварительная смета. Цены - ориентиры, не коммерческое предложение |

## Итоги (внизу листа «Смета»)

| Строка | Формула |
|---|---|
| Итого по блокам 1-9, ₽ без НДС | сумма итогов блоков |
| Агентское вознаграждение, ₽ | итого по блокам x процент агентского |
| База для НДС, ₽ | итого по блокам + агентское |
| НДС 20 %, ₽ | база x процент НДС (начисляется один раз) |
| **Итого с НДС, ₽** | база + НДС |
| Бюджет клиента, ₽ | из шапки |
| Разница с бюджетом, ₽ и % | бюджет минус итого с НДС |

## Лист «Допущения и риски»

| Раздел | Содержание |
|---|---|
| Допущения | список: число гостей, формат ночёвки, длительность банкета, процент агентского, база цен без НДС |
| Что не учтено | позиции, которых нет в брифе, но они возможны (страховка, проживание, подарки, оплата работы подрядчиков в выходные) |
| Риски бюджета | высокий сезон, срочность, курс, подтверждение вместимости, райдеры артистов |
| Вопросы клиенту | пробелы из брифа |
| Где нужен поиск | позиции со статусом «нужен поиск» |

## Лист «Источники»

| Позиция | Поставщик | Ссылка | Дата проверки | Что подтверждено (цена с сайта, вместимость, наличие услуги) |
|---|---|---|---|---|

## Пометки в ячейках

- «оценка» - цена рыночная, ориентир, не подтверждена.
- «по прайсу сайта, [дата]» - цена взята с проверенной страницы поставщика.
- «нужен поиск» - в колонках «Поставщик» и «Ссылка на поставщика», если проверенного поставщика найти не удалось. Выдуманные ссылки запрещены.
- «допущение» - значение принято без подтверждения клиента.
